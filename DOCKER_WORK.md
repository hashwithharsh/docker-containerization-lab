# Docker work in this project

The application under `vote/`, `result/`, `worker/`, `seed-data/`, and `healthchecks/` comes from Docker's Example Voting App sample.

My work in this repository is focused on understanding and operating the application with Docker: image builds, Dockerfiles, Compose networking, health checks, persistent storage, caching, image size, and troubleshooting.

Upstream project: https://github.com/dockersamples/example-voting-app

I am keeping the upstream application separate from the Docker changes so I can explain exactly what I worked on.
